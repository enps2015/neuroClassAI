## 📌 Documento Canônico de Consolidação e Handoff

- **[Dossier Técnico Completo do Projeto (NEUROCLASS_AI_PROJECT_DOSSIER.md)](./NEUROCLASS_AI_PROJECT_DOSSIER.md):** Especificação técnica exaustiva, inventário de componentes, contratos de dados, auditoria de segurança, relatório do experimento controlado com IA real (Golden Dataset) e guia de transição para o próximo desenvolvedor.

## Estrutura da Documentação

A pasta `docs/` está estritamente organizada nas seguintes categorias:

```
docs/
├── NEUROCLASS_AI_PROJECT_DOSSIER.md  # Dossier técnico canônico e guia de handoff
├── evidence/                         # Registros brutos de execuções experimentais com IA real (.json)
├── planos/                           # Especificações arquiteturais e planos de implementação (Fases 1 e 2)
├── relatorios/                       # Relatórios técnicos, auditorias e homologações formais
└── evidencias/                       # Capturas visuais e evidências de testes em ambiente real (.png)
```
